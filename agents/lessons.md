# Pinterest quality lessons

- A technical URL, dimension check or upstream category match does not establish visual appeal or even correct product use. The saved hair-tools page contained a toy hairdresser set, so a blind fallback after rejecting the white brush photo would have made the Pin worse.
- A reviewed page must select the actual approved product/photo pair only while that exact candidate remains eligible. If it changes or becomes unavailable, omit that particular Pin until another hero is reviewed while automatic posting continues on the other pages.
- Show actual same-page before/after at card size. Different appealing products can explain a visual standard but cannot substitute for proving the actual selector's behavior.
- Treat animal/person context versus an isolated product as an editorial choice, not proof of superior aesthetics or click-through. Never infer quality from country of manufacture or restore a luxury-only gate.
- Read the entire affected README section after adding a new explanation so an older adjacent paragraph cannot contradict the resulting behavior.
